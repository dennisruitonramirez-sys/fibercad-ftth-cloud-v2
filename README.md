# FiberCAD FTTH Pro — Paquete Cloud v2

Estructura separada para desplegar y editar tus proyectos FTTH desde cualquier lugar:

- `frontend/` — Interfaz web y motor óptico en navegador.
- `backend/` — API REST en Node.js + Express (`server.js`, `store.js`, `opticalService.js`).
- `database/` — Esquema SQL (`schema.sql`) y datos iniciales (`seed.sql`).
- `.env.example` y `docker-compose.yml` — Plantillas para entorno en la nube.
